

# 🖥️ Codificação Back-End

Este repositório foi criado para centralizar projetos, códigos e estudos focados no desenvolvimento Back-End de aplicações web utilizando o ecossistema do JavaScript.

---

## 🎯 Objetivos

* **Dominar o ecossistema Node.js:** Compreender o funcionamento assíncrono e a arquitetura baseada em eventos.
* **Construir APIs RESTful:** Desenvolver endpoints eficientes, seguros e bem estruturados.
* **Praticar as boas práticas:** Aplicar conceitos de rotas, middlewares, tratamento de erros e manipulação de requisições/respostas HTTP.

---

## 📚 Conteúdo

O repositório está dividido em módulos que abordam desde conceitos iniciais até a criação de servidores completos:
* 📁 **Fundamentos:** Estrutura inicial do Node.js e manipulação de módulos nativos.
* 📁 **Rotas e Parâmetros:** Manipulação de Query, Route e Body params com Express.
* 📁 **Middlewares:** Camadas de validação, autenticação e tratamento global de erros.
* 📁 **Integrações:** Simulação de dados e conexão com fluxos de requisição do cliente.

---

## 🛠️ Ferramentas Utilizadas

O desenvolvimento deste ecossistema conta com as seguintes ferramentas e tecnologias:

* **JavaScript / Node.js:** O ambiente de execução runtime utilizado para rodar JavaScript no servidor.
* **Express:** O framework web minimalista escolhido para gerenciar rotas, middlewares e requisições HTTP de forma ágil.
* **NPM (Node Package Manager):** Gerenciador de pacotes utilizado para instalar e gerenciar as dependências do projeto.
* **Git & GitHub:** Para controle de versão do código e gerenciamento do repositório.

---

## 🚀 Como Executar o Repositório Localmente

1. Clone o repositório:
```bash
git clone https://github.com
```

2. Instale as dependências com o NPM:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm start
```
